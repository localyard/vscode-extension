# Changelog

## 0.1.0

First release.

- Projects and Services views with live status from `yard events`
- Start, stop, restart, setup, open, share, logs and PHP/Node switching
- Status bar item for the open folder's project
- New terminals get the project's runtimes and `yard.toml` environment
- `yard.toml` schema for Even Better TOML
- Offers to install the `yard` command when it's missing
